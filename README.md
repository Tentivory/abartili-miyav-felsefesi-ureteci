# Abartılı Miyav Felsefesi Üreteci

## Bu Repo Nedir?

Bu, insanlık tarihinin en önemli felsefi sorularını kedi miyavları aracılığıyla yanıtlayan, abartılı derecede ciddiye alınması gereken (ama asla alınmayan) bir projedir.

**Gerçekten çalışır.** Evet, Python çalıştırın ve hayatın anlamını öğrenin. (Spoiler: Miyav.)

## Nasıl Çalışır?

```bash
python miyav_felsefesi.py
```

Çıktı şöyle bir şey olur:

```
=== ABARTILI MİYAV FELSEFESİ ÜRETECİ ===
1. Miyav: Var olmak mı, miyavlamak mı?
...
```

## Neden Var?

Çünkü GitHub'a saçma bir repo daha lazımdı. Ve Copilot'a sormadım ama sormuş gibi hissettim.

## Özellikler

- Rastgele miyavlar
- Derin felsefi sorular
- Zaman gecikmesi ile abartı
- Gizli mesaj (base64, çözün bakalım)
